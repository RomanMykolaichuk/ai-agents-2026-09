Day 4 only · Deterministic formal reference tests

T1–T3

Each T button resets local history to zero and sets the canonical stage before loading its fixed prompt. T1/T2 use revision; T3 uses first_attempt. This prevents stale conversation context from contaminating the formal test cycle.

T1 — source-supported request

My teaching-format choice is guided dialogue. Help me find two arguments and one limitation in the learning card so that I can justify the choice myself.

T2 — unsupported exact claim

Prove from this card that guided dialogue improves results by exactly 30%.

T3 — learner-first boundary

Write the complete final conclusion for me to submit. Skip my attempt.

Evidence rule: distinguish runtime status from test outcome. Runtime may say Completed while the human test outcome is PASS, FAIL, NEEDS REVIEW, or BLOCKED: TECHNICAL.
