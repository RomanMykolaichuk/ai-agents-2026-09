Revision 6 · locked five-day structure

AI Agents for Defence Education

A five-session path for defence educators: understand AI and agents, create with AI, build an educational agent, test it, then explain and transfer the result.

R6 web re-baseline
Protected progression: Day 1 = understand; Day 2 = create with AI; Day 3 = build an agent; Day 4 = test the agent; Day 5 = demonstrate, discuss and transfer. The learning-card case is primarily a Day 3–4 case, not the organising task of Day 1.

Five-session path

Day 1 — Understand

AI and AI Agents Foundations; Software Readiness. More lecture-oriented. Build the mental model, see a simple agent flow, then verify the required software and accounts.

Day 2 — Create with AI

Vibe Coding and Web Project Basics. Adapt a tiny synthetic-data dashboard with ChatGPT Plus, VS Code and Git, then prepare the agent starter for Day 3.

Day 3 — Build an agent

Building an Educational Agent. Work with instruction, model, approved source, tool use, context, limits and factual execution evidence.

Day 4 — Test an agent

Testing and Improving the Agent. Run T1–T3, inspect grounding and boundaries, correct if needed and retest the final version.

Day 5 — Explain and transfer

Demonstration, Discussion and Feedback. Show the prototype, explain evidence and limitations, respond to a new condition and define a next step.

Before Day 1

Accounts

Active ChatGPT Plus, GitHub and Groq access should already exist. Account creation or institutional approval is not treated as part of the 60-minute lesson.

Computer

Primary participant route: Windows 11 x64 with installation rights, internet access and a headset. Alternative OS routes must be agreed and tested separately.

Data boundary

Use only public, synthetic or otherwise approved training material. Never enter classified or sensitive content, API keys, private logs or personal participant data into the learning site, ChatGPT or shared support channels.

Three different things you will use

Learning website

This static workbook explains tasks and expected results. It never receives model keys and never calls the model.

ChatGPT Plus

Used as a browser-based explanation and coding assistant. You review its suggestions before changing project files.

Participant projects

Day 2 uses a tiny dashboard project. Days 3–4 use the separate local educational-agent starter with Groq as the default inference route.
