Core glossary

Model

The language model that generates a response from supplied context. It is only one part of the agentic application.

Agentic application

An application that combines instructions/context, a model, approved actions/tools, observations, limits and human control.

Tool

A capability the application exposes to the model. In this workshop the core tool is read-only and allow-listed.

Grounding

Using an approved source for factual support instead of inventing unsupported evidence.

Factual log

Application evidence of what action/tool actually ran. Model prose saying “I used the source” is not equivalent evidence.

Bounded change

A deliberately small change with explicit scope, expected result, evidence and recovery path.

Checkpoint

A known-good version/state that can be identified and restored before later work.

Technical error

A runtime/provider failure. It must be recovered before scoring behavioural quality.

Instructor required

A state where the application intentionally stops because a configured boundary or schema requires human intervention.

Human outcome

Day 4 evidence label: PASS / FAIL / NEEDS REVIEW / BLOCKED: TECHNICAL. It is separate from runtime status.
